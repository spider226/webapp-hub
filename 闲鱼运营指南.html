一、部署上线（必须先做）

方案A：GitHub Pages（推荐，免费）

  1. 注册 GitHub 账号：github.com/signup
  2. 创建新仓库，命名为 webapp-hub
  3. 在项目目录执行以下命令：
cd "C:\Users\Administrator\Desktop\项目\webapp-hub" git remote add origin https://github.com/你的用户名/webapp-hub.git git branch -M main git push -u origin main
  1. 进入仓库 Settings → Pages → Source 选 main 分支 → Save
  2. 等待1-2分钟，你的网站就在 https://你的用户名.github.io/webapp-hub/ 上线了

⚠ 如果国内访问 GitHub Pages 慢，可以同时部署到 Vercel（注册后用 GitHub 账号导入即可，也免费）

方案B：Vercel（国内访问更快）

  1. 打开 vercel.com，用 GitHub 账号登录
  2. 点击 "New Project" → 选择 webapp-hub 仓库 → Deploy
  3. 自动获得 https://webapp-hub.vercel.app 域名

三、商品主图制作指南

每个商品需要 5张主图 + 1个视频（可选但推荐）

5张主图规划：

  1. 第1张：封面图 — 应用名称 + 一句卖点，纯色背景 + 大字标题（Canva做）
  2. 第2张：手机截图 — 应用在手机上的主界面（F12开发者工具截图）
  3. 第3张：功能截图 — 展示1-2个核心功能
  4. 第4张：卖点总结 — 3个核心优势（无需下载/隐私安全/永久使用）
  5. 第5张：使用说明 — 如何添加到手机桌面（三步教程）

截图工具：

  • 电脑端：浏览器按 F12 → 切换设备工具栏(Ctrl+Shift+M) → 选 iPhone 14 Pro → 截图
  • 手机端：直接在手机上打开网站截图

封面图制作：

  • 用 Canva（免费）
  • 画布尺寸：800x800px（闲鱼标准）
  • 背景：渐变色或纯色（建议用应用的主题色）
  • 文字：大号粗体，3-5个字即可

五、买家常见问题话术

买家问你回答
需要下载吗？ 不需要，浏览器打开就能用。加到手机桌面后和App一模一样。
数据安全吗？ 所有数据只保存在你的手机里，不上传到任何服务器，比App还安全。
能改功能吗？ 标准版含固定功能，如果需要定制可以拍我的定制链接，按需求报价。
换手机了数据还在吗？ 可以用导出功能把数据备份到文件，换手机后导入即可。
能用多久？ 永久使用。只要网站还在，你就能一直用。
为什么这么便宜？ AI辅助开发效率高，我想积累好评和销量，后面会涨价的~
能退款吗？ 虚拟商品发货后不支持退款，但功能问题免费修到满意为止。

六、注意事项与风险提醒

  1. ⚠ 绝对不要主动引导客户加微信，闲鱼聊天中提"加微信"可能被检测为导流封号。如果买家主动问，可以说"闲鱼沟通更方便"
  2. ⚠ 不要用"小程序"这个词如果商品不是真正的微信小程序。用"小工具""轻应用""网页工具"代替
  3. 商品发布时选择 "虚拟商品" 分类，不要选实物
  4. 不要直接搬运别人的图片和文案，自己做
  5. 前几单可以让朋友拍，积累真实好评
  6. 定价策略：前期低价（9.9-19.9）冲销量，30单后涨价到29.9-39.9
